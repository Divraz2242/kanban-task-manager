Kanban Task Manager - A browser-based Kanban task management application built using HTML, CSS, and vanilla JavaScript. 
This project allows users to create, manage, and organize tasks across different workflow stages with drag-and-drop functionality and persistent storage.

Features-
1.) Add tasks to different columns
2.) Edit tasks using a custom right-click context menu
3.) Delete tasks
4.) Drag and drop tasks between columns
5.) Data persistence using Local Storage
6.) Automatic task restoration on page reload
